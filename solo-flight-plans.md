## KSBP ops (every flight)

**Airspace / freqs**

- Class D while tower open (~0600–2000 local); otherwise Class G + CTAF
- ATIS 120.6 → Ground 121.6 → Tower/CTAF 124.0
- TPA ~1,200 MSL (~991 AGL + field elev ~212)
- RWY 29 calm-wind runway; left traffic all runways
- Noise-sensitive — fly published pattern; no hotdogging over town

**Standard flow**

1. ATIS
2. Ground: location, _closed traffic_ or _south/northwest departure_, ATIS code
3. Run-up
4. Tower: ready, intentions
5. Pattern: report legs only if asked; read back clearances (_option_ / T&G / land)
6. Last lap: “full stop”
7. Ground to parking

**Personal rules (≈2 months off)**

- Stop early if radio/scan feels behind
- No maneuvers below what Doug briefed
- Cancel if weather &lt; your mins (especially dusk / rain days)

## Practice areas

### Oceano / over the water (south) — primary for airwork

- South toward Oceano (L52) / shoreline, then slightly offshore for clear air
- From KSBP: request **south departure** → leave Class D → work south
- Watch coast stratus/fog; stay high enough you’d be comfortable if the engine quit
- Don’t bust L52 pattern for stalls; monitor CTAF if you get low near it

### Morro Bay (northwest) — ground reference

- NW toward Morro Bay / MQO, clear of town when possible
- From KSBP: request **northwest / west departure** → clear Class D
- Stay west of the hills for water/coast work, or stay high inland
- Don’t grind maneuvers low over Morro / Cayucos

**Altitude (confirm with Doug):** typically ≥3,000–3,500 MSL for steep turns / slow flight / stalls over water.

**Leave / return scripts**

- Out: “San Luis Ground, [callsign] AKS, **south departure** (or northwest), taxi with [ATIS].”
- Back: “San Luis Tower, [callsign], [position — e.g. 5 south / over Oceano], **inbound full stop** with [ATIS].”

| Day type         | Area                        |
| ---------------- | --------------------------- |
| Pattern-only     | Stay in KSBP closed traffic |
| First airwork    | Oceano / ocean              |
| Ground reference | Morro Bay                   |
